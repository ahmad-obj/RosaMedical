# Scissors Batch 01 Plan Erratum

Date: 2026-08-02
Applies to: `docs/superpowers/plans/2026-08-02-scissors-batch-01-production-media.md`

The original implementation plan reversed the Iris and Stevens catalogue suffix matrices. The uploaded client catalogue text table is authoritative and supersedes those lines and code examples.

## Correct mapping

### Iris Scissors — 10.5 cm

- Regular Straight: `04-0901`
- Regular Curved: `04-0911`
- Super Cut Straight: `05-0901`
- Super Cut Curved: `05-0911`
- Tungsten Carbide Straight: `06-0901`
- Tungsten Carbide Curved: `06-0911`

### Stevens Scissors — 9.5 cm and 11.5 cm

- Regular Straight: `04-0800`, `04-0802`
- Regular Curved: `04-0810`, `04-0812`
- Super Cut Straight: `05-0800`, `05-0802`
- Super Cut Curved: `05-0810`, `05-0812`
- Tungsten Carbide Straight: `06-0800`, `06-0802`
- Tungsten Carbide Curved: `06-0810`, `06-0812`

## Execution rule

Any plan step, sample assertion, reuse scope, or source-ledger row that conflicts with this erratum must use this corrected mapping. Asset IDs and image filenames remain unchanged because the Wave 1 images were named by the visually correct instrument family; only their catalogue-code associations required correction.
